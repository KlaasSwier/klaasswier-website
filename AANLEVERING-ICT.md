# Aanlevering aan ICT

## Opdracht

Publiceer deze statische website op `https://klaasswier.nl`.

## Gewenste inrichting

- Gebruik een nieuwe, aparte GitHub-repository voor deze website, bijvoorbeeld `KlaasSwier/klaasswier-website`.
- Laat de bestaande repository en publicatie van `uren.klaasswier.nl` volledig ongemoeid.
- De website kan via een afzonderlijk Vercel-project worden gepubliceerd, maar kan ook op een gewone webserver worden geplaatst.
- Stel `www.klaasswier.nl` bij voorkeur in als doorverwijzing naar `klaasswier.nl`.
- Schakel HTTPS in.
- Controleer vóór de omzetting de tijdelijke publicatie op desktop en mobiel.
- Maak vóór een DNS-wijziging een back-up of export van de huidige DNS-zone.

## Technische informatie

- Type: statische HTML-website
- Startbestand: `index.html`
- Afbeeldingen: map `assets`
- Build command: geen
- Database: geen
- Omgevingsvariabelen/geheime sleutels: geen
- Server-side code: geen

## Controle na publicatie

- Achtergrondfoto en drie logo's worden geladen.
- Navigatie en sticky header werken.
- Telefoon- en e-maillinks openen correct.
- Externe links naar Slagerij Islam Centrum en Google Maps werken.
- `klaasswier.nl` en `www.klaasswier.nl` gebruiken een geldig SSL-certificaat.
- `uren.klaasswier.nl` blijft naar de bestaande urenregistratie verwijzen.
